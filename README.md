# Patchwork by Brock Adams

## Project Description
An interactive narrative loosely inspired by Frankenstein; or, The Modern Prometheus, by Mary Shelley. The narrative uses chance operations to randomly select from a collection Tarot cards which dictates the narrative connections made by the user. The combination of random chance encounters also determine the ending of the narrative for the user.

## How to Run on Windows 11
### (ONLINE)
1. On the Patchwork repository, click **github-pages** under **Deployments** on the right side of the page.
2. Within **github-pages** click on latest deployment at the top of the screen.
3. **OR** access live page with this URL: **https://br907888.github.io/patchwork/**
